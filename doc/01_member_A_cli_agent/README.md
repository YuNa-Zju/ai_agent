## 最小交付

第一版必须完成：

1. `ie-agent chat` 或 `python -m ie_agent.cli.main chat` 可以启动。
2. 能连续读取用户输入。
3. 能识别 slash commands 和普通问题。
4. 普通问题能构造 `AgentRequest`。
5. 能调用 `AgentOrchestrator.run()`。
6. 能输出 `AgentResponse.answer`。
7. `/trace on` 后能显示 `RouteDecision`。
8. 即使 B/C/D 的真实模块没完成，也能用 mock 跑通。

## Router 规则

先用规则路由，不要一开始就依赖本地小模型。

### 课程标签

- 包含“电压、电流、电阻、欧姆、分压、RC”：`circuits`
- 包含“卷积、傅里叶、LTI、冲激响应、频域”：`signals`
- 包含“真值表、逻辑、Verilog、触发器、时序”：`digital_logic`
- 包含“信息熵、互信息、信道容量、BSC、编码”：`information_theory`
- 包含“CKM”：`ckm`

### intent

- 要求“计算、求、算、生成真值表”：`calculation`
- 要求“解释、说明、区别、为什么”：`concept`
- 包含“根据资料、课件、讲义、引用”：`rag_qa`
- 包含“报错、仿真不对、波形、debug”：`experiment_debug`
- 包含“报告、总结、摘要”：`report`
- 包含 `/mcp`、`/skill` 或扩展安装：`extension`

### need_rag

以下情况设为 true：

- 用户明确说“根据资料/讲义/课件”。
- 概念题属于课程知识。
- 报告总结需要引用资料。

### need_tool

以下情况设为 true：

- 明确要求数值计算。
- 出现工具关键词，如“卷积、熵、信道容量、分压、真值表”。

## CLI 命令优先级

优先完成：

1. `/help`
2. `/exit`
3. `/trace on|off`
4. `/model local|remote|auto`
5. `/rag on|off`
6. `/tools list`
7. `/budget show`
8. `/session save|load`

后续再接：

1. `/mcp add|list|enable|disable|remove`
2. `/skill install|list|enable|disable|remove`
3. `/eval run`

## 远程模型

使用 OpenAI-compatible 风格接口，方便 DeepSeek/Qwen 切换。

配置从环境变量读取：

```text
IE_AGENT_MODEL_PROVIDER=deepseek
DEEPSEEK_API_KEY=...
QWEN_API_KEY=...
IE_AGENT_BASE_URL=...
IE_AGENT_MODEL_NAME=...
```

如果 API key 缺失，不能崩溃，应该返回：

```text
remote model unavailable: missing API key
fallback answer generated by rule mode
```

## 与成员 B 对接

成员 B 交付 `RagService`。你只需要关心：

```python
if decision.need_rag:
    rag_result = rag_service.search(
        RagQuery(
            query=decision.query_rewrite or request.user_query,
            course_tags=decision.course_tags,
            top_k=5,
        )
    )
```

不要在 Agent 里自己读向量库。

## 与成员 C 对接

成员 C 交付 `ToolRegistry`。你只需要：

```python
tool_call = tool_registry.run("entropy", {"probabilities": [0.5, 0.5]})
```

不要直接 import `entropy()` 之类函数。
